UI/UX Projects

I've been coding and designing for years, building digital products ranging from full-stack web applications and mobile apps to AI interfaces. Explore my key UI/UX case studies below.

Occurency

Role: Lead UI Designer ┃ Senior Capstone

For my senior Web Application Programming project, I served as Lead UI Designer for Occurency—an intuitive event planning application. Beyond visual aesthetics, I was responsible for bridging the gap between complex back-end data architecture and a seamless front-end experience.

I established the core CSS framework that maintained brand consistency across all user flows, focusing on friction-free navigation and accessible event discovery.

Crocs Swim Log

Role: UI/UX Designer ┃ Mobile App

Born out of my experience as a national-level collegiate swimmer, Crocs Swim Log is an Android application engineered to help athletes track workout telemetry poolside with zero friction.

I designed a clean, ergonomic bottom-navigation system optimized for one-handed touch interactions, paired with a high-contrast, energetic visual palette tailored for active pool deck environments.

explAIn

Role: Lead UX/UI Designer ┃ Web Application

explAIn was designed as an accessible AI chatbot frontend tailored specifically for non-digital native demographics (ages 50+). Developed during my Writing for the Web coursework, the goal was demystifying AI interactions.

I structured a top-to-bottom conversational visual flow, high-legibility typography hierarchies, and simplified input controls to minimize cognitive load and enhance user confidence.
